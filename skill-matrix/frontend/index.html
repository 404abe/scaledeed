🎤 5-Minute Pitch Deck & Judge Walkthrough
🎯 The 5-Minute Hackathon Formula: 1 min Problem & Vision → 2 min Live Demo → 1 min Technical Architecture & Schema → 1 min Judge Q&A.

1. The Problem & Vision

Consultants lack clear, role-specific roadmaps ("Where am I now and how do I level up?"), while Academy Leads fly blind without visibility into the team's collective skill vulnerabilities.

2. Live Demo Highlights

  • Role Selection & Core Top-5: Switch between Developer, QA, Scrum Master with instant target recalculation.
  • Real-time Progress Sliders: Update level, watch gap badge react immediately, and persist via LocalStorage.
  • SMART Targeter: Converts any gap into an actionable 5-part goal with deadline and remaining days.
  • The Learning Bridge: Direct links to LinkedIn Learning, YouTube, and live GitHub API data.
  • Academy Lead Heatmap: Cross-team matrix identifying collective deficit gaps.

3. Technical Highlights & The "Explain-Back" Rule

  • PostgreSQL / Supabase Schema: 3NF normalized tables with composite primary keys and automated gap views (`skill_gap_view`, `employee_goal_progress`).
  • Zero Black-Box Code: Clean vanilla ES6 architecture with modular data stores, event delegation, and real-time state synchronization.
  • Live API Integration: Direct asynchronous fetch to public developer repositories with resilient fallback.
